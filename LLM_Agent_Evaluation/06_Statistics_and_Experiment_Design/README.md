# Part 6 — Statistics & Experiment Design

## 核心问题

观察到的分数变化是否可信、是否足以支持比较结论？

## 计划主题

- Estimand & Unit of Analysis
- Uncertainty & Confidence Intervals
- Bootstrap
- Paired Tests & Permutation
- Inter-rater Agreement
- Power & Sample Size
- Multiple Comparisons
- Calibration / Correlation / Ranking

## 原则

以 Eval 场景驱动统计知识，不扩展成完整统计教材。每个方法都必须回答：它解决哪个评测问题、假设是什么、常见误用是什么。
