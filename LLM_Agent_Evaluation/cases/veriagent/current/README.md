# VeriAgent — Current Implementation Cases

本目录只描述“当前实现如何体现 Evaluation 原则”。

每个 case 必须使用 `templates/CURRENT_CASE.md`，至少包含：

- `last_reviewed`；
- stable evaluation principle；
- repository / file pointers；
- current behavior；
- relevant trace fields；
- current metrics；
- known limitations；
- drift conditions。

这里的内容允许随着 VeriAgent 更新；历史实验结果不要放在这里。
