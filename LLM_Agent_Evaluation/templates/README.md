# Templates

本目录定义知识库各类文档的统一 contract。模板不是形式主义；它用于防止长期维护后出现同一类文档字段完全不同、无法检索和比较的问题。

- `CONCEPT_NOTE.md`
- `CORE_QUESTION.md`
- `PATTERN_CARD.md`
- `METRIC_CARD.md`
- `BENCHMARK_CARD.md`
- `FAILURE_CARD.md`
- `CURRENT_CASE.md`
- `FROZEN_EXPERIMENT.md`
- `LAB.md`
- `INTERVIEW_CARD.md`

模板字段可演化，但已有 frozen experiment 不因模板升级而回写。
