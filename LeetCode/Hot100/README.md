# LeetCode Hot 100 个人题库

> 共享维护母版：后续以本文件为准持续修改，不再依赖聊天中来回传递 Word / Markdown 文件。
>
> 题单基准：LeetCode「热题 100」学习计划。
>
> 默认语言：Python 3。

## 目标

这份题库不是“刷题打卡记录”，而是面向面试复习的个人算法知识库。最终目标是：

1. Hot 100 范围内尽量不出现完全不会的题；
2. 能从题目特征识别算法 Pattern，而不是只记题号；
3. 核心母题可以独立写出；
4. 每道题保留标准解法，同时逐渐叠加个人错误、二刷记录和口述思路。

## 四个复习入口

- **[核心母题 CORE_QUESTIONS.md](CORE_QUESTIONS.md)**：49 道母题，分为 40 道 M1 和 9 道 M2；优先决定“先刷什么”。
- **[算法模板库 TEMPLATES.md](TEMPLATES.md)**：解决“看到这类题应该想到什么”，包含识别信号、invariant、代码骨架、易错点和对应 Hot 100 题目。
- **[`solutions/`](solutions/)**：卡在具体实现时，再查看各专题的标准参考答案。
- **本 README 的 Master List**：负责 100 题总览、专题导航和个人掌握状态。

推荐顺序：

```text
母题优先级 → 识别 Pattern → 尝试默写模板 → 独立完成 → 卡住再看标准答案 → 记录错误
```

## 母题标记

- `⭐ M1`：**必须独立写出**。目标是 15–20 分钟内完成主解法，并能解释 invariant、复杂度和关键边界。
- `◆ M2`：**必须理解并能推导**。不要求机械背代码，但不能成为盲区。
- 无标记：第二阶段变体 / 补充技巧题。不是“不重要”，而是用于验证模板迁移能力。
- `[ ]`：仅表示当前尚未完成个人掌握度确认，与 M1/M2 固定分类无关。

详细理由与刷题顺序见 [`CORE_QUESTIONS.md`](CORE_QUESTIONS.md)。

## 每题统一结构

后续每道题尽量维护以下字段：

- 题号 / 题名 / 难度
- 核心 Pattern
- 题意摘要
- 标准思路
- Python 3 标准主解法
- 时间 / 空间复杂度
- 关键易错点
- 优先级：S / A / B
- 掌握度：🟢 / 🟡 / 🟠 / 🔴
- 是否母题
- 我的错误记录
- 二刷 / 三刷记录

# 维护约定

- `[ ]` 暂不表示“从未做过”，只是当前尚未完成个人掌握度确认；之后会根据实际情况改成更细的状态。
- `M1 / M2` 是相对稳定的学习优先级标签，不随个人完成状态变化。
- 标准答案优先采用面试中主流、可解释、复杂度可靠的写法，而不是追求最短代码。
- 同一道题有多种合理方案时，保留一套“标准主解法”，必要时补充替代方案。
- 后续个人笔记可以直接写入对应专题文件；README 主要负责总表、状态和导航。
