### 第 001 / 100 题｜1. 两数之和（简单）

**核心模式：** 哈希表 / 补数查询

**题意摘要：** 在数组中找到两个下标，使对应元素之和等于 target。

**标准思路：** 从左到右扫描。对当前数 x，只需判断 target-x 是否已经出现；若出现立即返回，否则记录 x 的下标。

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        pos = {}
        for i, x in enumerate(nums):
            need = target - x
            if need in pos:
                return [pos[need], i]
            pos[x] = i
        return []
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** 先查再存，避免同一个元素被使用两次。

### 第 002 / 100 题｜49. 字母异位词分组（中等）

**核心模式：** 哈希表 / 规范化键

**题意摘要：** 把互为字母异位词的字符串分到同一组。

**标准思路：** 异位词排序后结果相同。用排序后的字符串作为哈希键，将原字符串追加到对应分组。

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)
        for s in strs:
            key = ''.join(sorted(s))
            groups[key].append(s)
        return list(groups.values())
```

**复杂度：** 设字符串平均长度为 k：时间 O(n·k log k)，空间 O(nk)。

**关键易错点：** 若面试追求 O(nk)，可用 26 个字母计数元组作为 key。

### 第 003 / 100 题｜128. 最长连续序列（中等）

**核心模式：** 哈希集合 / 只从序列起点扩展

**题意摘要：** 给定无序数组，求最长连续整数序列长度，要求整体接近 O(n)。

**标准思路：** 把元素放入 set。只有当 x-1 不在集合中时，x 才是某段连续序列的起点；从起点向右扩展并更新最长长度。

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        s = set(nums)
        ans = 0
        for x in s:
            if x - 1 not in s:
                y = x
                while y in s:
                    y += 1
                ans = max(ans, y - x)
        return ans
```

**复杂度：** 均摊时间 O(n)，空间 O(n)。

**关键易错点：** 关键是“只从起点扩展”；否则会退化成 O(n²)。

### 第 004 / 100 题｜283. 移动零（简单）

**核心模式：** 快慢指针 / 原地覆盖

**题意摘要：** 保持非零元素相对顺序，把所有 0 移到数组末尾。

**标准思路：** slow 指向下一个应放非零元素的位置；fast 扫描数组，遇到非零就与 slow 位置交换。

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

**复杂度：** 时间 O(n)，额外空间 O(1)。

**关键易错点：** 题目要求原地修改，不要创建新数组作为最终答案。

### 第 005 / 100 题｜11. 盛最多水的容器（中等）

**核心模式：** 左右双指针 / 贪心缩边

**题意摘要：** 选择两条竖线形成容器，使面积最大。

**标准思路：** 面积受较短边限制。每次计算当前面积后，移动较短的那一侧；移动长边不可能在宽度变小的同时突破短边瓶颈。

```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        ans = 0
        while l < r:
            ans = max(ans, (r - l) * min(height[l], height[r]))
            if height[l] <= height[r]:
                l += 1
            else:
                r -= 1
        return ans
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 理解“为什么移动短边”比记代码更重要。

<a id="item-6"></a>
### 第 006 / 100 题｜15. 三数之和（中等）

**核心模式：** 排序 + 双指针 + 去重

**题意摘要：** 找出所有不重复的三元组，使三数之和为 0。

**标准思路：** 先排序。固定第一个数 i，在右侧用 l/r 双指针寻找 -nums[i]；固定值和命中后都要跳过重复元素。

```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        ans = []
        n = len(nums)
        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            if nums[i] > 0:
                break
            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s < 0:
                    l += 1
                elif s > 0:
                    r -= 1
                else:
                    ans.append([nums[i], nums[l], nums[r]])
                    l += 1
                    r -= 1
                    while l < r and nums[l] == nums[l - 1]:
                        l += 1
                    while l < r and nums[r] == nums[r + 1]:
                        r -= 1
        return ans
```

**复杂度：** 时间 O(n²)，排序带来 O(log n)~O(n) 额外空间（依实现）。

**关键易错点：** 去重分两层：固定的 i 去重；命中后的 l、r 去重。

<a id="item-7"></a>
### 第 007 / 100 题｜42. 接雨水（困难）

**核心模式：** 左右双指针 / 单侧上界

**题意摘要：** 柱状图中计算能接住的雨水总量。

**标准思路：** 维护 left_max/right_max。哪一侧当前柱子更低，就可以确定该侧位置的水量，因为它的有效瓶颈已由该侧最大值和另一侧至少同等高度保证。

```python
class Solution:
    def trap(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        left_max = right_max = 0
        ans = 0
        while l < r:
            if height[l] <= height[r]:
                left_max = max(left_max, height[l])
                ans += left_max - height[l]
                l += 1
            else:
                right_max = max(right_max, height[r])
                ans += right_max - height[r]
                r -= 1
        return ans
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 另一经典解法是单调栈；双指针版本更适合面试快速实现。

### 第 008 / 100 题｜3. 无重复字符的最长子串（中等）

**核心模式：** 可变长滑动窗口 / 最近位置

**题意摘要：** 求不含重复字符的最长连续子串长度。

**标准思路：** 记录每个字符最近出现位置。右指针扩展时，如字符在当前窗口中出现过，left 直接跳到其上次位置后一位。

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}
        left = 0
        ans = 0
        for right, ch in enumerate(s):
            if ch in last and last[ch] >= left:
                left = last[ch] + 1
            last[ch] = right
            ans = max(ans, right - left + 1)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(字符集大小)。

**关键易错点：** left 只能向右移动，不能被旧位置拉回去。

<a id="item-9"></a>
### 第 009 / 100 题｜438. 找到字符串中所有字母异位词（中等）

**核心模式：** 固定长滑动窗口 / 频次匹配

**题意摘要：** 在 s 中找出所有长度与 p 相同且字符频次一致的子串起点。

**标准思路：** 窗口长度固定为 len(p)。维护 need 和 window 计数；每次加入右端字符，若窗口过长则移出左端，再比较计数。

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        if len(p) > len(s):
            return []
        need = Counter(p)
        window = Counter()
        ans = []
        m = len(p)
        for r, ch in enumerate(s):
            window[ch] += 1
            if r >= m:
                left_ch = s[r - m]
                window[left_ch] -= 1
                if window[left_ch] == 0:
                    del window[left_ch]
            if r >= m - 1 and window == need:
                ans.append(r - m + 1)
        return ans
```

**复杂度：** 时间近似 O(n)（字符集固定时），空间 O(字符集大小)。

**关键易错点：** 若字符集为固定 26 个小写字母，可用长度 26 的数组进一步降低常数。

### 第 010 / 100 题｜560. 和为 K 的子数组（中等）

**核心模式：** 前缀和 + 哈希计数

**题意摘要：** 统计和等于 k 的连续子数组数量。

**标准思路：** 若当前前缀和为 pre，需要之前出现过 pre-k。哈希表记录每种前缀和值出现次数；初始化 {0:1} 处理从下标 0 开始的子数组。

```python
class Solution:

        count = defaultdict(int)
        count[0] = 1
        pre = 0
        ans = 0
        for x in nums:
            pre += x
            ans += count[pre - k]
            count[pre] += 1
        return ans
```

### 第 011 / 100 题｜239. 滑动窗口最大值（困难）

**核心模式：** 单调队列 / deque

**题意摘要：** 对每个长度为 k 的滑动窗口，返回窗口最大值。

**标准思路：** 双端队列保存“下标”，且对应值单调递减。新元素入队前弹出所有不大于它的尾部元素；队首若已出窗口则移除。

```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        q = deque()
        ans = []
        for i, x in enumerate(nums):
            while q and nums[q[-1]] <= x:
                q.pop()
            q.append(i)
            if q[0] <= i - k:
                q.popleft()
            if i >= k - 1:
                ans.append(nums[q[0]])
        return ans
```

**复杂度：** 时间 O(n)，空间 O(k)。

**关键易错点：** 队列存下标而不是值，才能判断元素是否已经离开窗口。

### 第 012 / 100 题｜76. 最小覆盖子串（困难）

**核心模式：** 可变长滑动窗口 / 满足计数后收缩

**题意摘要：** 在 s 中找包含 t 所有字符及其次数的最短子串。

**标准思路：** 右端扩张直到窗口满足需求；满足后不断收缩左端并更新最优答案。用 formed 记录已有多少种字符达到所需次数。

```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not t or not s:
            return ''
        need = Counter(t)
        window = defaultdict(int)
        required = len(need)
        formed = 0
        left = 0
        best_len = float('inf')
        best_l = 0

        for right, ch in enumerate(s):
            window[ch] += 1
            if ch in need and window[ch] == need[ch]:
                formed += 1

            while formed == required:
                if right - left + 1 < best_len:
                    best_len = right - left + 1
                    best_l = left
                c = s[left]
                window[c] -= 1
                if c in need and window[c] < need[c]:
                    formed -= 1
                left += 1

        return '' if best_len == float('inf') else s[best_l:best_l + best_len]
```

**复杂度：** 时间 O(|s|+|t|)，空间 O(字符集大小)。

**关键易错点：** formed 统计“达标的字符种类数”，不是窗口中字符总数。

### 第 014 / 100 题｜56. 合并区间（中等）

**核心模式：** 排序 + 区间扫描

**题意摘要：** 合并所有有重叠的闭区间。

**标准思路：** 按左端点排序。若当前区间起点大于结果最后区间终点，则开新区间；否则扩展最后区间的右端点。

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])
        ans = []
        for l, r in intervals:
            if not ans or l > ans[-1][1]:
                ans.append([l, r])
            else:
                ans[-1][1] = max(ans[-1][1], r)
        return ans
```

**复杂度：** 时间 O(n log n)，空间 O(n)（输出不计时额外可视为 O(log n) 排序栈）。

**关键易错点：** 闭区间 [1,4] 与 [4,5] 视为重叠，条件应是 l > last_r 才分开。

### 第 015 / 100 题｜189. 轮转数组（中等）

**核心模式：** 三次反转

**题意摘要：** 将数组向右轮转 k 个位置，要求原地。

**标准思路：** k 先对 n 取模。整体反转，再反转前 k 个，再反转剩余部分。

```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n

        def rev(l: int, r: int) -> None:
            while l < r:
                nums[l], nums[r] = nums[r], nums[l]
                l += 1
                r -= 1

        rev(0, n - 1)
        rev(0, k - 1)
        rev(k, n - 1)
```

```python
class Solution:

        n = len(nums)
        ans = [1] * n
        prefix = 1
        for i in range(n):
            ans[i] = prefix
            prefix *= nums[i]
```

### 第 017 / 100 题｜41. 缺失的第一个正数（困难）

**核心模式：** 原地哈希 / 下标归位

**题意摘要：** 在 O(n) 时间、O(1) 额外空间内找未出现的最小正整数。

**标准思路：** 长度 n 的答案只可能在 [1,n+1]。把值 x 尽量交换到下标 x-1；归位后第一个 nums[i] != i+1 的位置就是答案。

```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        for i in range(n):
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                j = nums[i] - 1
                nums[i], nums[j] = nums[j], nums[i]
        for i, x in enumerate(nums):
            if x != i + 1:
                return i + 1
        return n + 1
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** while 条件必须防止重复值导致死循环。

### 第 018 / 100 题｜73. 矩阵置零（中等）

**核心模式：** 原地标记 / 首行首列

**题意摘要：** 若某位置为 0，则将其整行整列置 0，要求原地。

**标准思路：** 利用第一行和第一列充当标记数组；额外用两个布尔量记录第一行/第一列原本是否含 0。

```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        row0 = any(matrix[0][j] == 0 for j in range(n))
        col0 = any(matrix[i][0] == 0 for i in range(m))

        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        if row0:
            for j in range(n):
                matrix[0][j] = 0
        if col0:
            for i in range(m):
                matrix[i][0] = 0
```

**复杂度：** 时间 O(mn)，空间 O(1)。

**关键易错点：** 第一行和第一列同时承担标记职责，所以原始状态要先单独保存。

### 第 019 / 100 题｜54. 螺旋矩阵（中等）

**核心模式：** 边界模拟

**题意摘要：** 按顺时针螺旋顺序遍历矩阵。

**标准思路：** 维护 top/bottom/left/right 四条边界，每轮依次走上边、右边、下边、左边；每走完一边收缩对应边界，并在必要时检查边界仍合法。

```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1
        ans = []
        while top <= bottom and left <= right:
            for j in range(left, right + 1):
                ans.append(matrix[top][j])
            top += 1

            for i in range(top, bottom + 1):
                ans.append(matrix[i][right])
            right -= 1

            if top <= bottom:
                for j in range(right, left - 1, -1):
                    ans.append(matrix[bottom][j])
                bottom -= 1

            if left <= right:
                for i in range(bottom, top - 1, -1):
                    ans.append(matrix[i][left])
                left += 1
        return ans
```

**复杂度：** 时间 O(mn)，空间 O(1)（不计输出）。

**关键易错点：** 走下边和左边前必须重新判断边界，避免单行/单列重复访问。

**核心模式：** 右上角阶梯搜索

**题意摘要：** 矩阵每行递增、每列递增，判断 target 是否存在。

**标准思路：** 从右上角开始：当前值太大就左移，太小就下移；每一步排除一整行或一整列。

```python
class Solution:

            return False
        i, j = 0, len(matrix[0]) - 1
        while i < len(matrix) and j >= 0:

            else:
                i += 1
        return False
```

```python
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
```

```python
class Solution:
```

```python
        tail = dummy
        while list1 and list2:
            if list1.val <= list2.val:
                tail.next, list1 = list1, list1.next
```

### 第 028 / 100 题｜2. 两数相加（中等）

**核心模式：** 链表模拟加法 / 进位

**题意摘要：** 两个链表按低位到高位存储非负整数，返回它们的和。

**标准思路：** 同步遍历两链表，缺失位按 0 处理，并维护 carry；循环条件要包含 carry。

```python
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        tail = dummy
        carry = 0
        while l1 or l2 or carry:
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0
            total = x + y + carry
            carry, digit = divmod(total, 10)
            tail.next = ListNode(digit)
            tail = tail.next
            l1 = l1.next if l1 else None
            l2 = l2.next if l2 else None
        return dummy.next
```

**复杂度：** 时间 O(max(m,n))，空间 O(max(m,n))（输出链表）。

**关键易错点：** 最后一位可能产生新的进位，因此 while 条件中要有 carry。

### 第 029 / 100 题｜19. 删除链表的倒数第 N 个结点（中等）

**核心模式：** 快慢指针 + dummy

**题意摘要：** 删除倒数第 n 个节点并返回头结点。

**标准思路：** dummy 指向 head。fast 先走 n 步，再让 fast/slow 同步走到 fast.next 为空；此时 slow.next 正是待删节点。

```python
class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        fast = slow = dummy
        for _ in range(n):
            fast = fast.next
        while fast.next:
            fast = fast.next
            slow = slow.next
        slow.next = slow.next.next
        return dummy.next
```

**复杂度：** 时间 O(L)，空间 O(1)。

**关键易错点：** 从 dummy 出发更容易统一“删除头结点”的情况。

### 第 030 / 100 题｜24. 两两交换链表中的节点（中等）

**核心模式：** dummy + 局部指针重连

**题意摘要：** 每两个相邻节点交换一次，不能只交换值。

**标准思路：** 让 prev 始终指向待交换两节点之前的位置，保存 a、b 后按 prev→b→a→next 的顺序重连。

```python
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy
        while prev.next and prev.next.next:
            a = prev.next
            b = a.next
            a.next = b.next
            b.next = a
            prev.next = b
            prev = a
        return dummy.next
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 交换后 prev 应移动到原来的第一个节点 a。

### 第 031 / 100 题｜25. K 个一组翻转链表（困难）

**核心模式：** 分组定位 + 区间反转

**题意摘要：** 每 k 个节点作为一组翻转；不足 k 个保持原顺序。

**标准思路：** 用 group_prev 指向每组前驱，先找到第 k 个节点；若不足则结束。保存 group_next，再反转 [group_prev.next, group_next) 并重新连接。

```python
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        group_prev = dummy

        while True:
            kth = group_prev
            for _ in range(k):
                kth = kth.next
                if not kth:
                    return dummy.next
            group_next = kth.next

            prev, cur = group_next, group_prev.next
            while cur is not group_next:
                nxt = cur.next
                cur.next = prev
                prev = cur
                cur = nxt

            old_head = group_prev.next
            group_prev.next = kth
            group_prev = old_head
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 反转区间的 prev 初值应设为 group_next，便于翻转后自然接回后续链表。

### 第 032 / 100 题｜138. 随机链表的复制（中等）

**核心模式：** 哈希映射 / 两遍复制

**题意摘要：** 深拷贝带 next 和 random 指针的链表。

**标准思路：** 第一遍为每个原节点创建副本并建立 old→new 映射；第二遍利用映射连接副本的 next/random。

```python
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None
        mp = {None: None}
        cur = head
        while cur:
            mp[cur] = Node(cur.val)
            cur = cur.next
        cur = head
        while cur:

        return mp[head]
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** 可进一步用“原节点后插副本节点”做到 O(1) 额外空间，但哈希版更清晰稳妥。

### 第 033 / 100 题｜148. 排序链表（中等）

**核心模式：** 归并排序 / 快慢指针

**题意摘要：** 在 O(n log n) 时间内对链表排序。

**标准思路：** 链表适合归并排序：快慢指针从中间断开，递归排序两半，再用合并有序链表模板合并。

```python
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        mid = slow.next
        slow.next = None

        left = self.sortList(head)
        right = self.sortList(mid)

        dummy = ListNode(0)
        tail = dummy
        while left and right:
            if left.val <= right.val:
                tail.next, left = left, left.next
            else:
                tail.next, right = right, right.next
            tail = tail.next
        tail.next = left or right
        return dummy.next
```

**复杂度：** 时间 O(n log n)，递归栈空间 O(log n)。

**关键易错点：** 切分时必须 slow.next = None，否则递归不会缩小。

### 第 034 / 100 题｜23. 合并 K 个升序链表（困难）

**核心模式：** 最小堆

**题意摘要：** 合并 k 条升序链表。

**标准思路：** 把每条非空链表头压入最小堆；每次弹出最小节点接到结果，并把该节点的 next 入堆。为避免节点不可比较，堆元素加入唯一序号。

```python
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        heap = []
        uid = 0
        for node in lists:
            if node:
                heappush(heap, (node.val, uid, node))
                uid += 1

        dummy = ListNode(0)
        tail = dummy
        while heap:
            _, _, node = heappop(heap)
            tail.next = node
            tail = tail.next
            if node.next:
                heappush(heap, (node.next.val, uid, node.next))
                uid += 1
        return dummy.next
```

**复杂度：** 设总节点数 N：时间 O(N log k)，空间 O(k)。

**关键易错点：** Python 堆在前两个字段相同时会继续比较第三字段；加入 uid 可避免比较 ListNode。

### 第 035 / 100 题｜146. LRU 缓存（中等）

**核心模式：** 哈希表 + 双向链表（Python OrderedDict）

**题意摘要：** 实现固定容量的最近最少使用缓存，get/put 平均 O(1)。

**标准思路：** Python 标准库 OrderedDict 已封装哈希表+双向链表语义：访问后 move_to_end；超容量时 popitem(last=False) 淘汰最久未使用项。

```python
class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.data:
            return -1
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key: int, value: int) -> None:
        if key in self.data:
            self.data.move_to_end(key)
        self.data[key] = value
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)
```

**复杂度：** get/put 均摊 O(1)，空间 O(capacity)。

**关键易错点：** 面试若禁止 OrderedDict，需要手写“哈希表 + 双向链表”；原理必须会解释。

### 第 036 / 100 题｜94. 二叉树的中序遍历（简单）

**核心模式：** 迭代栈

**题意摘要：** 按“左-根-右”顺序返回二叉树节点值。

**标准思路：** 一路把左链入栈；栈顶弹出后访问，再转向其右子树，重复上述过程。

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans, stack = [], []
        cur = root
        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            ans.append(cur.val)
            cur = cur.right
        return ans
```

**复杂度：** 时间 O(n)，空间 O(h)。

**关键易错点：** 迭代模板是树遍历基础；递归版本更短但面试常要求会迭代。

### 第 039 / 100 题｜101. 对称二叉树（简单）

**核心模式：** 镜像递归

**题意摘要：** 判断一棵树是否关于根节点轴对称。

**标准思路：** 比较两棵子树是否镜像：节点值相等，且 a.left 对应 b.right、a.right 对应 b.left。

```python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def mirror(a, b):
            if not a or not b:
                return a is b
            return (a.val == b.val and
                    mirror(a.left, b.right) and
                    mirror(a.right, b.left))
        return mirror(root.left, root.right) if root else True
```

**复杂度：** 时间 O(n)，空间 O(h)。

**关键易错点：** 对称比较不是“左右子树结构相同”，而是交叉镜像。

### 第 040 / 100 题｜543. 二叉树的直径（简单）

**核心模式：** 后序 DFS / 高度贡献

**题意摘要：** 求任意两节点之间最长路径的边数。

**标准思路：** DFS 返回节点向下的最大深度；经过当前节点的直径为 left_depth + right_depth，用全局变量更新最大值。

```python
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def depth(node):
            nonlocal ans
            if not node:
                return 0
            l = depth(node.left)
            r = depth(node.right)
            ans = max(ans, l + r)
            return 1 + max(l, r)

        depth(root)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(h)。

**关键易错点：** DFS 返回的是“深度”，全局更新的是“直径”；两个量不要混。

### 第 041 / 100 题｜102. 二叉树的层序遍历（中等）

**核心模式：** BFS / 队列

**题意摘要：** 按层从上到下返回每层节点值。

**标准思路：** 队列做 BFS；每轮先记录当前队列长度 size，只弹出这 size 个节点组成一层。

```python
class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        q = deque([root])
        ans = []
        while q:
            level = []
            for _ in range(len(q)):
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            ans.append(level)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(w)，w 为最大层宽。

**关键易错点：** for range(len(q)) 的 len(q) 在循环开始时取值，正好锁定当前层。

### 第 042 / 100 题｜108. 将有序数组转换为二叉搜索树（简单）

**题意摘要：** 把升序数组转换成高度平衡 BST。

**标准思路：** 每次取区间中点作为根，左右两半递归构造左右子树。

```python
class Solution:

            root = TreeNode(nums[m])

        return build(0, len(nums) - 1)
```

**关键易错点：** 取左中点或右中点都可以，只要保持平衡。

### 第 043 / 100 题｜98. 验证二叉搜索树（中等）

**核心模式：** 中序严格递增

**题意摘要：** 判断二叉树是否满足 BST：每个节点左子树都小于它，右子树都大于它。

**标准思路：** BST 的中序遍历应严格递增。迭代中序时保存前一个访问值，若当前值 <= prev 则失败。

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        stack = []
        cur = root
        prev = None
        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            if prev is not None and cur.val <= prev:
                return False
            prev = cur.val
            cur = cur.right
        return True
```

**复杂度：** 时间 O(n)，空间 O(h)。

**关键易错点：** 只比较节点与直接孩子不够；BST 约束作用于整棵左右子树。

### 第 044 / 100 题｜230. 二叉搜索树中第 K 小的元素（中等）

**核心模式：** BST 中序遍历

**题意摘要：** 返回 BST 中第 k 小的节点值。

**标准思路：** BST 中序遍历天然升序；迭代中序每弹出一个节点就令 k-1，减到 0 时返回。

```python
class Solution:

        stack = []
        cur = root
        while True:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            k -= 1
            if k == 0:
                return cur.val
            cur = cur.right
```

### 第 047 / 100 题｜105. 从前序与中序遍历序列构造二叉树（中等）

**核心模式：** 分治 + 中序索引表

**题意摘要：** 由无重复元素的前序和中序遍历重建二叉树。

**标准思路：** 前序首元素是根；在中序中找到根即可确定左子树大小。用哈希表 O(1) 获取中序位置，并通过下标区间递归。

```python
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        idx = {v: i for i, v in enumerate(inorder)}

        def build(pl, pr, il, ir):
            if pl > pr:
                return None
            root_val = preorder[pl]
            k = idx[root_val]
            left_size = k - il
            root = TreeNode(root_val)
            root.left = build(pl + 1, pl + left_size, il, k - 1)
            root.right = build(pl + left_size + 1, pr, k + 1, ir)
            return root

        n = len(preorder)
        return build(0, n - 1, 0, n - 1)
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** 左右递归边界最容易写错，先明确 left_size 再推下标。

### 第 048 / 100 题｜437. 路径总和 III（中等）

**核心模式：** 树上前缀和 + 回溯计数

**题意摘要：** 统计树中向下连续路径和等于 targetSum 的路径数量；路径不要求从根开始或到叶结束。

**标准思路：** DFS 维护从根到当前节点的前缀和 cur；若之前出现过 cur-target，就得到相应数量的合法路径。进入节点时加计数，离开时减计数，体现回溯。

```python
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        prefix = defaultdict(int)
        prefix[0] = 1

        def dfs(node, cur):
            if not node:
                return 0
            cur += node.val
            ans = prefix[cur - targetSum]
            prefix[cur] += 1
            ans += dfs(node.left, cur)
            ans += dfs(node.right, cur)
            prefix[cur] -= 1
            return ans

        return dfs(root, 0)
```

**复杂度：** 时间 O(n)，空间 O(h)~O(n)。

**关键易错点：** 离开当前递归分支时必须 prefix[cur]-=1，避免不同分支之间互相污染。

### 第 049 / 100 题｜236. 二叉树的最近公共祖先（中等）

**核心模式：** 后序 DFS

**题意摘要：** 在普通二叉树中寻找两个给定节点 p、q 的最近公共祖先。

**标准思路：** 若当前节点是 p/q 直接返回；递归左右子树。左右都非空说明 p/q 分居两侧，当前节点即 LCA；否则返回非空的一侧。

```python
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root or root is p or root is q:
            return root
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root
        return left or right
```

**复杂度：** 时间 O(n)，空间 O(h)。

**关键易错点：** 这是普通二叉树版本，不要误用 BST 的大小比较性质。

### 第 050 / 100 题｜124. 二叉树中的最大路径和（困难）

**核心模式：** 后序 DFS / 单边贡献

**题意摘要：** 路径可从任意节点到任意节点，但相邻节点必须由边连接；求最大路径和。

**标准思路：** DFS 返回“从当前节点向父节点能提供的最大单边贡献”，负贡献截断为 0；经过当前节点的完整路径可同时取左右两边，用它更新全局答案。

```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        ans = float('-inf')

        def gain(node):
            nonlocal ans
            if not node:
                return 0
            left = max(0, gain(node.left))
            right = max(0, gain(node.right))
            ans = max(ans, node.val + left + right)
            return node.val + max(left, right)

        gain(root)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(h)。

**关键易错点：** “返回给父节点”的路径不能同时走左右两边；全局候选才可以。

### 第 051 / 100 题｜200. 岛屿数量（中等）

**核心模式：** DFS/BFS 连通块

**题意摘要：** 0/1 网格中，按上下左右相邻统计由 1 组成的岛屿数量。

**标准思路：** 遍历网格，每遇到一个未访问陆地就把答案加 1，并 DFS/BFS 把这一整块陆地全部标记为已访问。

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])

        def dfs(i, j):
            if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
                return
            grid[i][j] = '0'
            dfs(i + 1, j)
            dfs(i - 1, j)
            dfs(i, j + 1)
            dfs(i, j - 1)

        ans = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '1':
                    ans += 1
                    dfs(i, j)
        return ans
```

**复杂度：** 时间 O(mn)，最坏递归栈 O(mn)。

### 第 052 / 100 题｜994. 腐烂的橘子（中等）

**核心模式：** 多源 BFS

**题意摘要：** 腐烂橘子每分钟感染上下左右的新鲜橘子，求全部腐烂所需最短时间；无法完成返回 -1。

**标准思路：** 把所有初始腐烂橘子同时入队作为 BFS 第 0 层，并统计 fresh 数量；逐层扩散，每发生一层有效感染时间加 1。

```python
class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j))
                elif grid[i][j] == 1:
                    fresh += 1

        minutes = 0
        dirs = [(1,0), (-1,0), (0,1), (0,-1)]
        while q and fresh:
            for _ in range(len(q)):
                i, j = q.popleft()
                for di, dj in dirs:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                        grid[ni][nj] = 2
                        fresh -= 1
                        q.append((ni, nj))
            minutes += 1
        return minutes if fresh == 0 else -1
```

**复杂度：** 时间 O(mn)，空间 O(mn)。

**关键易错点：** 这是典型多源 BFS：所有起点必须一开始同时入队。

### 第 053 / 100 题｜207. 课程表（中等）

**核心模式：** 拓扑排序 / 入度

**题意摘要：** 根据先修关系判断是否能完成所有课程，本质是判断有向图是否无环。

**标准思路：** 构建邻接表和入度。把所有入度为 0 的节点入队，逐个删除其出边；若最终处理节点数等于课程数，则无环。

```python
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for course, pre in prerequisites:
            graph[pre].append(course)
            indeg[course] += 1

        q = deque(i for i in range(numCourses) if indeg[i] == 0)
        taken = 0
        while q:
            u = q.popleft()
            taken += 1
            for v in graph[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
        return taken == numCourses
```

**复杂度：** 时间 O(V+E)，空间 O(V+E)。

**关键易错点：** 边方向应是 prerequisite → course。

### 第 054 / 100 题｜208. 实现 Trie (前缀树)（中等）

**核心模式：** Trie

**题意摘要：** 支持插入单词、精确搜索单词、判断是否存在给定前缀。

**标准思路：** 每个节点保存 children 映射和 is_end 标记。insert 沿字符路径创建节点；search 走完整路径后还要检查 is_end；startsWith 只需路径存在。

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self.root
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

    def startsWith(self, prefix: str) -> bool:
        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return True
```

**复杂度：** 单次操作时间 O(L)，空间与所有插入字符总数同阶。

**关键易错点：** search 与 startsWith 的唯一区别是是否要求终点 is_end=True。

### 第 055 / 100 题｜46. 全排列（中等）

**核心模式：** 回溯 / used 数组

**题意摘要：** 返回无重复数组的所有排列。

**标准思路：** path 表示当前排列，used 标记哪些元素已被选择；当 path 长度等于 n 时加入答案。

```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        ans = []
        path = []
        used = [False] * len(nums)

        def dfs():
            if len(path) == len(nums):
                ans.append(path.copy())
                return
            for i, x in enumerate(nums):
                if used[i]:
                    continue
                used[i] = True
                path.append(x)
                dfs()
                path.pop()
                used[i] = False

        dfs()
        return ans
```

**复杂度：** 时间 O(n·n!)，空间 O(n)（不计输出）。

**关键易错点：** 加入答案时必须 path.copy()，否则后续回溯会修改已保存结果。

### 第 058 / 100 题｜39. 组合总和（中等）

**核心模式：** 回溯 / 可重复选择

**题意摘要：** 候选正整数可无限次使用，找所有和为 target 的组合。

**标准思路：** 先排序便于剪枝。dfs(start, remain) 中从 start 起枚举，因此组合不考虑顺序；递归仍传 i，使同一元素可再次使用。

```python
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        ans = []
        path = []

        def dfs(start, remain):
            if remain == 0:
                ans.append(path.copy())
                return
            for i in range(start, len(candidates)):
                x = candidates[i]
                if x > remain:
                    break
                path.append(x)
                dfs(i, remain - x)
                path.pop()

        dfs(0, target)
        return ans
```

**复杂度：** 复杂度与解空间相关，最坏指数级；递归深度最多约 target/min(candidates)。

**关键易错点：** “可重复选择”对应递归传 i；若不可重复通常传 i+1。

### 第 059 / 100 题｜22. 括号生成（中等）

**核心模式：** 回溯 / 合法性剪枝

**题意摘要：** 生成 n 对括号的所有合法组合。

**标准思路：** 记录已用左括号 open、右括号 close。只要 open<n 就能加左括号；只有 close<open 才能加右括号。

```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:

        path = []

        def dfs(opened, closed):
            if len(path) == 2 * n:
                ans.append(''.join(path))
                return
            if opened < n:
                path.append('(')
                dfs(opened + 1, closed)
                path.pop()
            if closed < opened:
                path.append(')')
                dfs(opened, closed + 1)
                path.pop()

        return ans
```

**复杂度：** 输出规模为第 n 个卡特兰数，时间与输出规模同阶。

### 第 060 / 100 题｜79. 单词搜索（中等）

**核心模式：** 网格 DFS + 回溯

**题意摘要：** 判断给定单词能否由网格中上下左右相邻单元格依次组成，同一格不能重复使用。

**标准思路：** 从每个可能起点 DFS。当前字符匹配后暂时把该格标记为已访问，探索四邻域，回溯时恢复。

```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])

        def dfs(i, j, k):
            if k == len(word):
                return True
            if i < 0 or i >= m or j < 0 or j >= n or board[i][j] != word[k]:
                return False
            ch = board[i][j]
            board[i][j] = '#'
            found = (dfs(i + 1, j, k + 1) or dfs(i - 1, j, k + 1) or
                     dfs(i, j + 1, k + 1) or dfs(i, j - 1, k + 1))
            board[i][j] = ch
            return found

        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True
        return False
```

**复杂度：** 最坏时间 O(mn·4^L)，递归空间 O(L)。

**关键易错点：** 无论成功失败，都应恢复 board；这里先保存 found 再恢复，避免短路返回漏恢复。

### 第 061 / 100 题｜131. 分割回文串（中等）

**核心模式：** 回溯 + 回文判断

**题意摘要：** 把字符串分割成若干子串，使每段都是回文，返回所有方案。

**标准思路：** 从 start 枚举结束位置 end，若 s[start:end+1] 是回文就加入 path 并递归处理剩余后缀。

```python
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        ans = []
        path = []

        def is_pal(l, r):
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True

        def dfs(start):
            if start == len(s):
                ans.append(path.copy())
                return
            for end in range(start, len(s)):
                if is_pal(start, end):
                    path.append(s[start:end + 1])
                    dfs(end + 1)
                    path.pop()

        dfs(0)
        return ans
```

**复杂度：** 最坏时间 O(n²·2^n)（含回文判断），空间 O(n)（不计输出）。

**关键易错点：** 可用 DP 预处理 isPalindrome 将回文判断降为 O(1)。

### 第 062 / 100 题｜51. N 皇后（困难）

**核心模式：** 回溯 + 列/对角线集合剪枝

**题意摘要：** 在 n×n 棋盘放置 n 个皇后，使任意两个不在同一列或对角线。

**标准思路：** 逐行放皇后。用 cols、diag1(row-col)、diag2(row+col) 三个集合 O(1) 判断冲突。

```python
class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        ans = []
        cols, diag1, diag2 = set(), set(), set()
        pos = [-1] * n

        def dfs(r):
            if r == n:
                board = []
                for c in pos:
                    board.append('.' * c + 'Q' + '.' * (n - c - 1))
                ans.append(board)
                return
            for c in range(n):
                if c in cols or r - c in diag1 or r + c in diag2:
                    continue
                pos[r] = c
                cols.add(c); diag1.add(r - c); diag2.add(r + c)
                dfs(r + 1)
                cols.remove(c); diag1.remove(r - c); diag2.remove(r + c)

        dfs(0)
        return ans
```

**复杂度：** 最坏约 O(n!)，递归空间 O(n)。

**关键易错点：** 两条对角线可分别用 row-col 与 row+col 唯一标识。

### 第 064 / 100 题｜74. 搜索二维矩阵（中等）

**核心模式：** 展平后二分

**题意摘要：** 矩阵每行升序，且下一行首元素大于上一行尾元素；判断 target 是否存在。

**标准思路：** 把 m×n 矩阵视作长度 mn 的有序数组，虚拟下标 idx 对应 matrix[idx//n][idx%n]。

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        l, r = 0, m * n - 1
        while l <= r:
            mid = (l + r) // 2
            x = matrix[mid // n][mid % n]
            if x == target:
                return True
            if x < target:
                l = mid + 1
            else:
                r = mid - 1
        return False
```

**复杂度：** 时间 O(log(mn))，空间 O(1)。

**关键易错点：** 注意它与 240 题“行列各自有序但行之间不严格连续”的结构不同。

### 第 065 / 100 题｜34. 在排序数组中查找元素的第一个和最后一个位置（中等）

**核心模式：** 两次边界二分

**题意摘要：** 在非递减数组中返回 target 的起止位置，不存在则 [-1,-1]。

**标准思路：** 实现 lower_bound(x)=第一个 >=x 的位置。left=lower_bound(target)，right=lower_bound(target+1)-1（整数 target）。

```python
class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def lower_bound(x):
            l, r = 0, len(nums)
            while l < r:
                m = (l + r) // 2
                if nums[m] < x:
                    l = m + 1
                else:
                    r = m
            return l

        left = lower_bound(target)
        if left == len(nums) or nums[left] != target:
            return [-1, -1]
        right = lower_bound(target + 1) - 1
        return [left, right]
```

**复杂度：** 时间 O(log n)，空间 O(1)。

**关键易错点：** 若元素类型不是整数，可改写 upper_bound（第一个 > target）而非 target+1。

### 第 066 / 100 题｜33. 搜索旋转排序数组（中等）

**核心模式：** 二分 / 判断哪一半有序

**题意摘要：** 无重复升序数组在某点旋转后，O(log n) 查找 target。

**标准思路：** 每次 mid 至少有一半仍有序。先判断左半还是右半有序，再看 target 是否落在该有序范围内，从而舍弃另一半。

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums) - 1
        while l <= r:
            m = (l + r) // 2
            if nums[m] == target:
                return m
            if nums[l] <= nums[m]:
                if nums[l] <= target < nums[m]:
                    r = m - 1
                else:
                    l = m + 1
            else:
                if nums[m] < target <= nums[r]:
                    l = m + 1
                else:
                    r = m - 1
        return -1
```

**复杂度：** 时间 O(log n)，空间 O(1)。

**关键易错点：** 边界中的 <= / < 要和有序区间定义一致。

### 第 067 / 100 题｜153. 寻找旋转排序数组中的最小值（中等）

**核心模式：** 二分 / 与右端比较

**题意摘要：** 无重复升序数组旋转后，找到最小元素。

**标准思路：** 比较 nums[mid] 与 nums[r]：若 mid 更大，最小值一定在右侧；否则最小值在 [l,mid]。最终 l==r。

```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        l, r = 0, len(nums) - 1
        while l < r:
            m = (l + r) // 2
            if nums[m] > nums[r]:
                l = m + 1
            else:
                r = m
        return nums[l]
```

**复杂度：** 时间 O(log n)，空间 O(1)。

**关键易错点：** 这里 r=m 而不是 m-1，因为 mid 本身可能就是最小值。

### 第 068 / 100 题｜4. 寻找两个正序数组的中位数（困难）

**核心模式：** 二分分割 / 较短数组

**题意摘要：** 在 O(log(m+n)) 量级内求两个有序数组的中位数。

**标准思路：** 在较短数组上二分切分位置 i，并令另一数组切分 j 使左半总元素数固定。合法切分满足 Aleft<=Bright 且 Bleft<=Aright；根据违反方向调整 i。

```python
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        A, B = nums1, nums2
        if len(A) > len(B):
            A, B = B, A
        m, n = len(A), len(B)
        total_left = (m + n + 1) // 2
        l, r = 0, m

        while l <= r:
            i = (l + r) // 2
            j = total_left - i
            Aleft = float('-inf') if i == 0 else A[i - 1]
            Aright = float('inf') if i == m else A[i]
            Bleft = float('-inf') if j == 0 else B[j - 1]
            Bright = float('inf') if j == n else B[j]

            if Aleft <= Bright and Bleft <= Aright:
                if (m + n) % 2:
                    return float(max(Aleft, Bleft))
                return (max(Aleft, Bleft) + min(Aright, Bright)) / 2.0
            elif Aleft > Bright:
                r = i - 1
            else:
                l = i + 1
```

**复杂度：** 时间 O(log(min(m,n)))，空间 O(1)。

**关键易错点：** 最难点不是代码，而是“左右两部分数量固定 + 左部所有值不大于右部”这两个条件。

### 第 069 / 100 题｜20. 有效的括号（简单）

**核心模式：** 栈 / 匹配

**题意摘要：** 判断括号字符串是否正确闭合并保持类型匹配。

**标准思路：** 左括号入栈；遇到右括号时要求栈非空且栈顶是对应左括号。扫描结束后栈必须为空。

```python
class Solution:
    def isValid(self, s: str) -> bool:
        mp = {')':'(', ']':'[', '}':'{'}
        stack = []
        for ch in s:
            if ch in mp:
                if not stack or stack.pop() != mp[ch]:
                    return False
            else:
                stack.append(ch)
        return not stack
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** 右括号到来时必须检查空栈；最后还要检查是否残留左括号。

### 第 070 / 100 题｜155. 最小栈（中等）

**核心模式：** 辅助栈 / 同步最小值

**题意摘要：** 实现 push/pop/top/getMin，所有操作 O(1)。

**标准思路：** 维护普通栈和 min_stack；每次 push 同步压入“截至当前位置的最小值”，pop 时两栈同步弹出。

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.mins = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.mins:
            self.mins.append(val)
        else:
            self.mins.append(min(val, self.mins[-1]))

    def pop(self) -> None:
        self.stack.pop()
        self.mins.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.mins[-1]
```

**复杂度：** 每个操作 O(1)，空间 O(n)。

**关键易错点：** 若辅助栈只在更小时入栈，则遇到重复最小值时要特别处理；同步栈更稳。

### 第 071 / 100 题｜394. 字符串解码（中等）

**核心模式：** 栈 / 状态保存

**题意摘要：** 把形如 k[encoded] 的字符串展开，支持嵌套。

**标准思路：** 扫描字符：数字累积倍数；遇到 [ 把当前字符串和倍数入栈并重置；遇到 ] 弹出上一层并拼接；普通字符加入当前字符串。

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        cur = ''
        num = 0
        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)
            elif ch == '[':
                stack.append((cur, num))
                cur = ''
                num = 0
            elif ch == ']':
                prev, k = stack.pop()
                cur = prev + cur * k
            else:
                cur += ch
        return cur
```

**复杂度：** 时间 O(输出长度)，空间 O(嵌套深度 + 输出临时空间)。

**关键易错点：** 倍数可能是多位数，需 num = num*10 + digit。

### 第 072 / 100 题｜739. 每日温度（中等）

**核心模式：** 单调递减栈

**题意摘要：** 对每一天，返回还要等几天才会遇到更高温度；没有则 0。

**标准思路：** 栈保存尚未找到更高温度的下标，且对应温度单调递减。新温度更高时持续弹栈并填写距离。

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        stack = []
        for i, t in enumerate(temperatures):
            while stack and temperatures[stack[-1]] < t:
                j = stack.pop()
                ans[j] = i - j
            stack.append(i)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** “下一个更大元素”是单调栈最经典识别信号。

### 第 073 / 100 题｜84. 柱状图中最大的矩形（困难）

**核心模式：** 单调递增栈 + 哨兵

**题意摘要：** 给定柱高，求能形成的最大矩形面积。

**标准思路：** 维护下标单调递增栈。遇到更矮柱时，弹出的柱高 h 以当前位置为右边界、弹栈后的新栈顶为左边界。两端加 0 哨兵统一结算。

```python
class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        arr = [0] + heights + [0]
        stack = [0]
        ans = 0
        for i in range(1, len(arr)):
            while arr[stack[-1]] > arr[i]:
                h = arr[stack.pop()]
                width = i - stack[-1] - 1
                ans = max(ans, h * width)
            stack.append(i)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** 宽度公式 i-stack[-1]-1 是核心；左右 0 哨兵可消除边界特判。

### 第 074 / 100 题｜215. 数组中的第 K 个最大元素（中等）

**核心模式：** 大小为 k 的最小堆

**题意摘要：** 返回数组排序后第 k 大元素，不要求返回排序结果。

**标准思路：** 维护大小最多为 k 的最小堆；遍历所有元素，超过 k 就弹出最小值。最终堆顶就是第 k 大。

```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        heap = []
        for x in nums:
            heappush(heap, x)
            if len(heap) > k:
                heappop(heap)
        return heap[0]
```

**复杂度：** 时间 O(n log k)，空间 O(k)。

**关键易错点：** 更优平均 O(n) 的 Quickselect 也常考；堆版最稳定易写。

### 第 075 / 100 题｜347. 前 K 个高频元素（中等）

**核心模式：** 计数 + 最小堆

**题意摘要：** 返回出现频率最高的 k 个元素。

**标准思路：** 先 Counter 统计频率，再维护大小为 k 的 (freq, value) 最小堆。

```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        freq = Counter(nums)
        heap = []
        for x, f in freq.items():
            heappush(heap, (f, x))
            if len(heap) > k:
                heappop(heap)
        return [x for _, x in heap]
```

**复杂度：** 设不同元素数为 m：时间 O(n + m log k)，空间 O(m+k)。

**关键易错点：** 若要求线性期望复杂度，可用桶排序；面试中堆法通常足够标准。

### 第 076 / 100 题｜295. 数据流的中位数（困难）

**核心模式：** 双堆

**题意摘要：** 支持不断加入数字，并随时返回当前所有数字的中位数。

**标准思路：** small 为最大堆（Python 用负数）保存较小一半，large 为最小堆保存较大一半；保持 len(small) 与 len(large) 差不超过 1，且 small 可多一个。

```python
class MedianFinder:
    def __init__(self):
        self.small = []   # max-heap via negatives
        self.large = []   # min-heap

    def addNum(self, num: int) -> None:
        heappush(self.small, -num)
        heappush(self.large, -heappop(self.small))
        if len(self.large) > len(self.small):
            heappush(self.small, -heappop(self.large))

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return float(-self.small[0])
        return (-self.small[0] + self.large[0]) / 2.0
```

**复杂度：** addNum O(log n)，findMedian O(1)，空间 O(n)。

**关键易错点：** 同时维护“数量平衡”和“small 中所有值 <= large 中所有值”。

### 第 077 / 100 题｜121. 买卖股票的最佳时机（简单）

**题意摘要：** 只能买一次卖一次，求最大利润。

```python
class Solution:
```

```python
class Solution:
```

### 第 079 / 100 题｜45. 跳跃游戏 II（中等）

**核心模式：** 贪心 / 分层覆盖

**题意摘要：** 保证能到达终点，求最少跳跃次数。

**标准思路：** 把一次跳跃能覆盖的范围看作一层。遍历当前层内所有位置更新 next_end；到达 current_end 时必须完成一次跳跃，并把边界扩到 next_end。

```python
class Solution:
    def jump(self, nums: List[int]) -> int:
        jumps = 0
        current_end = 0
        next_end = 0
        for i in range(len(nums) - 1):
            next_end = max(next_end, i + nums[i])
            if i == current_end:
                jumps += 1
                current_end = next_end
        return jumps
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 只遍历到 n-2，避免已经到终点后再多算一次跳跃。

### 第 080 / 100 题｜763. 划分字母区间（中等）

**核心模式：** 贪心 / 最后出现位置

**题意摘要：** 把字符串尽量切成更多片段，使同一字母只出现在一个片段内。

**标准思路：** 先记录每个字符最后出现位置。扫描当前片段时不断把 end 扩到所见字符的最远末位置；当 i==end 时即可切分。

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {ch: i for i, ch in enumerate(s)}
        ans = []
        start = end = 0
        for i, ch in enumerate(s):
            end = max(end, last[ch])
            if i == end:
                ans.append(end - start + 1)
                start = i + 1
        return ans
```

**复杂度：** 时间 O(n)，空间 O(字符集大小)。

**关键易错点：** 本质是把字符的覆盖区间做贪心合并，并在最早可闭合位置切段。

### 第 084 / 100 题｜279. 完全平方数（中等）

**核心模式：** 完全背包 / 最短组合数

**题意摘要：** 用若干完全平方数凑出 n，求最少数量。

**标准思路：** dp[x] 表示凑出 x 的最少个数。对每个 x 枚举不超过 x 的平方数 j²，转移 dp[x]=min(dp[x], dp[x-j²]+1)。

```python
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [0] + [float('inf')] * n
        squares = [i * i for i in range(1, int(n ** 0.5) + 1)]
        for x in range(1, n + 1):
            for sq in squares:
                if sq > x:
                    break
                dp[x] = min(dp[x], dp[x - sq] + 1)
        return dp[n]
```

**复杂度：** 时间 O(n√n)，空间 O(n)。

**关键易错点：** 也可把 0..n 看作图节点做 BFS；DP 更统一。

### 第 085 / 100 题｜322. 零钱兑换（中等）

**核心模式：** 完全背包 / 最少硬币数

**题意摘要：** 硬币可无限次使用，求凑成 amount 的最少硬币数；无法凑成返回 -1。

**标准思路：** dp[x] 表示凑出金额 x 的最少硬币数，初始 inf，dp[0]=0。对每个金额枚举 coin 更新 dp[x-coin]+1。

```python
class Solution:

        dp = [float('inf')] * (amount + 1)
        dp[0] = 0
        for x in range(1, amount + 1):
            for coin in coins:
                if coin <= x:
                    dp[x] = min(dp[x], dp[x - coin] + 1)
        return -1 if dp[amount] == float('inf') else dp[amount]
```

<a id="item-86"></a>
### 第 086 / 100 题｜139. 单词拆分（中等）

**核心模式：** DP / 前缀可达

**题意摘要：** 判断字符串能否由字典中的一个或多个单词拼接而成，单词可重复使用。

**标准思路：** dp[i] 表示 s[:i] 能否拆分。若存在 j<i，使 dp[j] 为真且 s[j:i] 在字典中，则 dp[i]=True。

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        max_len = max(map(len, wordDict)) if wordDict else 0
        for i in range(1, n + 1):
            for j in range(max(0, i - max_len), i):
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break
        return dp[n]
```

**复杂度：** 最坏时间 O(n²·切片代价)，空间 O(n+字典)。

**关键易错点：** dp[0]=True 是空前缀的关键基例。

**核心模式：** 贪心 + 二分 tails

**题意摘要：** 求严格递增子序列的最大长度。

**标准思路：** tails[i] 保存“长度为 i+1 的递增子序列能达到的最小尾值”。对每个 x，用 lower_bound 找第一个 >=x 的位置替换；若不存在则追加。

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []
        for x in nums:
            l, r = 0, len(tails)
            while l < r:
                m = (l + r) // 2
                if tails[m] < x:
                    l = m + 1
                else:
                    r = m
            if l == len(tails):
                tails.append(x)
            else:
                tails[l] = x
        return len(tails)
```

**复杂度：** 时间 O(n log n)，空间 O(n)。

**关键易错点：** tails 本身通常不是某条实际 LIS，只维护各长度的最小可能尾值。

### 第 088 / 100 题｜152. 乘积最大子数组（中等）

**核心模式：** DP / 同时维护最大最小乘积

**题意摘要：** 求乘积最大的非空连续子数组。

**标准思路：** 负数会把最大与最小互换，因此每个位置同时维护以它结尾的 max_prod 和 min_prod。遇到负数先交换两者，再更新。

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        max_prod = min_prod = ans = nums[0]
        for x in nums[1:]:
            if x < 0:
                max_prod, min_prod = min_prod, max_prod
            max_prod = max(x, max_prod * x)
            min_prod = min(x, min_prod * x)
            ans = max(ans, max_prod)
        return ans
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 最大子数组和只需一个状态；乘积题必须额外保留“最小负积”，它可能被下一个负数翻成最大正积。

### 第 089 / 100 题｜416. 分割等和子集（中等）

**核心模式：** 0/1 背包

**题意摘要：** 判断能否把数组分成两个元素和相等的子集。

**标准思路：** 总和必须为偶数。问题转为是否能选若干元素凑出 target=sum/2。用一维 0/1 背包布尔 dp，容量必须从大到小遍历。

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        target = total // 2
        dp = [False] * (target + 1)
        dp[0] = True
        for x in nums:
            for s in range(target, x - 1, -1):
                dp[s] = dp[s] or dp[s - x]
        return dp[target]
```

**复杂度：** 时间 O(n·target)，空间 O(target)。

**关键易错点：** 0/1 背包一维压缩必须倒序枚举容量，否则同一元素会被重复使用。

<a id="item-90"></a>
### 第 090 / 100 题｜32. 最长有效括号（困难）

**核心模式：** DP / 以位置结尾

**题意摘要：** 求最长连续合法括号子串长度。

**标准思路：** dp[i] 表示必须以 i 结尾的最长合法括号长度。只有 s[i]=")" 才可能更新，分前一位是 "(" 和 ")" 两种情况处理。

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        dp = [0] * n
        ans = 0
        for i in range(1, n):
            if s[i] == ')':
                if s[i - 1] == '(':
                    dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
                else:
                    j = i - dp[i - 1] - 1
                    if j >= 0 and s[j] == '(':
                        dp[i] = dp[i - 1] + 2
                        if j - 1 >= 0:
                            dp[i] += dp[j - 1]
                ans = max(ans, dp[i])
        return ans
```

**复杂度：** 时间 O(n)，空间 O(n)。

**关键易错点：** 关键下标 j=i-dp[i-1]-1，表示尝试与当前右括号匹配的左括号位置。

### 第 091 / 100 题｜62. 不同路径（中等）

**核心模式：** 二维 DP / 网格计数

**题意摘要：** 机器人只能向右或向下，从左上到右下，求路径数量。

**标准思路：** 到达 (i,j) 的路径来自上方和左方，因此 dp[j] 可用一维数组滚动：dp[j]=dp[j]+dp[j-1]。

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                dp[j] += dp[j - 1]
        return dp[-1]
```

**复杂度：** 时间 O(mn)，空间 O(n)。

**关键易错点：** 第一行和第一列路径数都为 1，因此可直接用全 1 初始化。

### 第 092 / 100 题｜64. 最小路径和（中等）

**核心模式：** 二维 DP / 网格最优值

**题意摘要：** 从左上到右下只能向右或向下，求路径数字之和最小值。

**标准思路：** dp[j] 表示当前行到该列的最小路径和；从上方 dp[j] 和左方 dp[j-1] 取较小者，再加当前格。

```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [float('inf')] * n
        dp[0] = 0
        for i in range(m):
            for j in range(n):
                if j == 0:
                    dp[j] = dp[j] + grid[i][j]
                else:
                    dp[j] = min(dp[j], dp[j - 1]) + grid[i][j]
        return dp[-1]
```

**复杂度：** 时间 O(mn)，空间 O(n)。

**关键易错点：** 一维压缩时 dp[j] 在更新前代表“上方”，dp[j-1] 已代表“左方”。

### 第 093 / 100 题｜5. 最长回文子串（中等）

**核心模式：** 中心扩展

**题意摘要：** 返回字符串中的最长回文连续子串。

**标准思路：** 每个回文都有一个中心。分别以单字符和相邻两字符作为中心向两侧扩展，记录最长区间。

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ''
        best_l = best_r = 0

        def expand(l, r):
            nonlocal best_l, best_r
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if r - l > best_r - best_l:
                    best_l, best_r = l, r
                l -= 1
                r += 1

        for i in range(len(s)):
            expand(i, i)
            expand(i, i + 1)
        return s[best_l:best_r + 1]
```

**复杂度：** 时间 O(n²)，空间 O(1)。

**关键易错点：** 虽然被放在多维 DP 专题，中心扩展通常是更简洁的标准面试解法。

### 第 094 / 100 题｜1143. 最长公共子序列（中等）

**核心模式：** 二维 DP

**题意摘要：** 求两个字符串最长公共子序列长度，子序列不要求连续。

**标准思路：** dp[i][j] 表示 text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度。字符相等则 +1，否则取舍弃其中一个末字符的最大值。用一维滚动压缩。

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        if len(text1) < len(text2):
            text1, text2 = text2, text1
        dp = [0] * (len(text2) + 1)
        for c1 in text1:
            prev = 0
            for j, c2 in enumerate(text2, 1):
                old = dp[j]
                if c1 == c2:
                    dp[j] = prev + 1
                else:
                    dp[j] = max(dp[j], dp[j - 1])
                prev = old
        return dp[-1]
```

**复杂度：** 时间 O(mn)，空间 O(min(m,n))。

**关键易错点：** 一维压缩中 prev 保存二维表的左上角 dp[i-1][j-1]。

### 第 095 / 100 题｜72. 编辑距离（中等）

**核心模式：** 二维 DP / 字符串编辑

**题意摘要：** 把 word1 转换成 word2，允许插入、删除、替换，每次代价 1，求最少操作数。

**标准思路：** dp[i][j] 表示 word1[:i] 到 word2[:j] 的最少操作。末字符相同则继承左上；否则 1+min(删除、插入、替换)。

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        prev = list(range(n + 1))
        for i in range(1, m + 1):
            cur = [i] + [0] * n
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    cur[j] = prev[j - 1]
                else:
                    cur[j] = 1 + min(prev[j], cur[j - 1], prev[j - 1])
            prev = cur
        return prev[n]
```

**复杂度：** 时间 O(mn)，空间 O(n)。

**关键易错点：** 三项分别对应：删 word1 当前字符、插入匹配 word2 当前字符、替换。

### 第 097 / 100 题｜169. 多数元素（简单）

**核心模式：** Boyer-Moore 投票

**题意摘要：** 找出出现次数超过 n/2 的元素，题目保证存在。

**标准思路：** 把不同元素两两抵消。维护 candidate 和 count；count 归零时换候选，相同 +1，不同 -1。最终剩下的一定是多数元素。

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        candidate = None
        count = 0
        for x in nums:
            if count == 0:
                candidate = x
            count += 1 if x == candidate else -1
        return candidate
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 若题目不保证多数元素存在，还需第二遍验证 candidate 频次。

### 第 098 / 100 题｜75. 颜色分类（中等）

**核心模式：** 荷兰国旗 / 三指针

**题意摘要：** 原地把只含 0、1、2 的数组按颜色排序。

**标准思路：** 维护 [0,left) 全为 0，[left,i) 全为 1，(right,n) 全为 2。遇 0 与 left 换并推进；遇 2 与 right 换但 i 暂不推进，因为换来的值尚未检查。

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:
        left, i, right = 0, 0, len(nums) - 1
        while i <= right:
            if nums[i] == 0:
                nums[left], nums[i] = nums[i], nums[left]
                left += 1
                i += 1
            elif nums[i] == 2:
                nums[i], nums[right] = nums[right], nums[i]
                right -= 1
            else:
                i += 1
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 交换 2 后不能立刻 i+=1，因为从右边换回来的元素还未分类。

### 第 099 / 100 题｜31. 下一个排列（中等）

**核心模式：** 字典序 / 找下降拐点

**题意摘要：** 把数组原地变成字典序中的下一个更大排列；若已最大则变为最小排列。

**标准思路：** 从右找第一个 nums[i]<nums[i+1] 的拐点；再从右找第一个大于 nums[i] 的元素交换；最后反转 i+1 之后的递减后缀使其最小。

```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        n = len(nums)
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        if i >= 0:
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
        l, r = i + 1, n - 1
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 目标是“最小幅度地变大”：拐点尽量靠右，替换值尽量小但必须更大，后缀再变为最小。

### 第 100 / 100 题｜287. 寻找重复数（中等）

**核心模式：** Floyd 判环映射

**题意摘要：** 长度 n+1 的数组元素均在 [1,n]，只有一个重复值（可重复多次），要求不修改数组且 O(1) 额外空间。

**标准思路：** 把下标 i 指向 nums[i] 看作链表。由于值域是 [1,n]，必然形成环；重复数就是环入口。用 Floyd 快慢指针先相遇，再从起点同步走到入口。

```python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = nums[0]
        fast = nums[nums[0]]
        while slow != fast:
            slow = nums[slow]
            fast = nums[nums[fast]]

        p = 0
        while p != slow:
            p = nums[p]
            slow = nums[slow]
        return p
```

**复杂度：** 时间 O(n)，空间 O(1)。

**关键易错点：** 不要把“值”与“下标”混淆：数组定义了函数 f(i)=nums[i]，重复值对应多个入边，形成环入口。
