# Hot 100 原题截图存放位置

这个目录为 `HOT100_顺序刷题合集.md` 中每道题的「原题截图」预留。

## 文件命名

使用**合集顺序号**作为图片名，而不是 LeetCode 原始题号：

- `001.png`：合集第 001 题（LeetCode 1 两数之和）
- `002.png`：合集第 002 题（LeetCode 49 字母异位词分组）
- …
- `100.png`：合集第 100 题

如果一题需要两张图，可以用 `001_2.png`、`001_3.png`。

## 上传与插入

1. 在 GitHub 打开本目录，选择 **Add file → Upload files** 上传截图并提交。
2. 在 [顺序刷题合集](../../HOT100_顺序刷题合集.md) 中找到对应题目，把「原题截图（待添加）」占位行替换为：

   `![第001题原题截图](images/questions/001.png)`

3. 如果有第二张图，紧接着添加：

   `![第001题原题截图-2](images/questions/001_2.png)`

图片路径相对于合集 Markdown 文件计算。

> **版权提醒：** 公开仓库中的截图对所有人可见。第三方题目原文及截图可能受版权保护；如果是完整题面截图，更稳妥的方式是在私有仓库或个人本地笔记保存，并在公开版中保留题意摘要与官方题目链接。
