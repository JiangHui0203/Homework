# LeetCode Hot 100 核心母题清单

> 目标：从 100 道 Hot 100 中抽出一组最值得反复练习的“母题”。母题不是“最难题”，而是能代表一个高复用 Pattern、值得形成条件反射的题。
>
> 总计：**49 道母题 = 40 道 M1 + 9 道 M2**。
>
> - **M1：必须独立写出。** 看到题目应能识别 Pattern，15–20 分钟内完成主解法，并能解释复杂度与关键 invariant。
> - **M2：必须理解并能推导。** 不要求机械背代码，但应能在少量提示下恢复完整解法。
> - 其余 51 道不是“不重要”，而是作为变体、补充技巧或二阶段强化题。

# 2. 40 道 M1：真正应该形成肌肉记忆

## 2.1 哈希 / 双指针 / 滑窗

### 1. 两数之和

**看到什么想到它：** “找另一个数满足关系”。

**必须会：**
- 为什么一遍哈希即可；
- 为什么要“先查后存”；
- 时间 O(n)、空间 O(n)。

### 128. 最长连续序列

**看到什么想到它：** 无序整数数组 + 连续值 + 要求 O(n)。

**必须会：**
- set 去重；
- 只有 `x - 1` 不存在时才从 x 开始扩展；
- 解释为什么总体仍是均摊 O(n)。

### 283. 移动零

**看到什么想到它：** 原地稳定压缩 / 移动。

**必须会：**
- slow 指向“下一个应该填非零元素的位置”；
- fast 扫描；
- 理解覆盖版和交换版区别。

### 15. 三数之和

**看到什么想到它：** 多数之和 + 去重。

**必须会：**
- 排序；
- 固定一个数后左右夹逼；
- 三层去重分别在哪里做。

### 3. 无重复字符的最长子串

**看到什么想到它：** 连续子串 + 最长 + 窗口约束。

**必须会：**
- right 扩张、left 收缩；
- 窗口 invariant；
- 为什么收缩通常是 `while` 而不是 `if`。

### 560. 和为 K 的子数组

**看到什么想到它：** 子数组和恰好等于 K；数组可能含负数。

**必须会：**
- `prefix[j] - prefix[i] = k` 转成“以前是否见过 `prefix-k`”；
- 哈希表保存前缀和出现次数；
- 初始 `{0: 1}` 的含义。

### 239. 滑动窗口最大值

**看到什么想到它：** 固定窗口 + 动态最大/最小值。

**必须会：**
- deque 存下标；
- 队列对应值单调递减；
- 队首过期、队尾淘汰、队首取答案。

### 76. 最小覆盖子串

**看到什么想到它：** 连续子串 + 覆盖条件 + 求最短。

**必须会：**
- 什么时候窗口“满足”；
- 满足后为什么要主动收缩；
- `need / window / valid` 的职责划分。

## 2.2 数组 / 区间

### 53. 最大子数组和

**必须会：**
- `dp[i]` 或滚动变量表示“以当前位置结尾的最大和”；
- 当前元素是重新开始还是接在前面；
- 写出 O(1) 空间版本。

### 56. 合并区间

**必须会：**
- 先按左端点排序；
- 当前区间与结果最后一个区间比较；
- 区分“重叠”和“完全分离”。

---

## 2.3 链表

### 206. 反转链表

**必须会：** `prev / cur / nxt` 三指针，不丢链。

### 141. 环形链表

**必须会：** 快慢指针为什么有环一定会相遇。

### 21. 合并两个有序链表

**必须会：** dummy 节点 + 两指针归并。

### 19. 删除链表的倒数第 N 个结点

**必须会：** dummy + 前后双指针保持固定距离。

### 25. K 个一组翻转链表

**必须会：**
- 先判断剩余是否够 K 个；
- 切出一段、反转、重新接回；
- 明确 `group_prev / kth / group_next` 三个边界。

---

## 2.4 二叉树

### 94. 中序遍历

**必须会：** 递归版和显式栈版至少熟一种，理解 `左 → 根 → 右`。

### 104. 最大深度

**必须会：** 自底向上 DFS 的标准骨架：

```python
def dfs(node):
    if not node:
        return 0
    return max(dfs(node.left), dfs(node.right)) + 1
```

### 102. 层序遍历

**必须会：** 队列 + 每轮固定处理当前层长度。

### 98. 验证二叉搜索树

**必须会：**
- 不能只比较父子节点；
- 上下界递归，或中序严格递增。

### 236. 最近公共祖先

**必须会：**
- 当前节点是 p/q 时返回自己；
- 左右都非空时当前节点就是 LCA；
- 否则把非空一侧向上传递。

---

## 2.5 图 / BFS

### 200. 岛屿数量

**必须会：** 找到一个未访问陆地后 Flood Fill 整个连通块，答案 +1。

### 994. 腐烂的橘子

**必须会：** 多源 BFS：所有初始腐烂橘子同时入队，按层推进时间。

### 207. 课程表

**必须会：**
- 邻接表 + 入度；
- 入度为 0 入队；
- 最终能否处理全部节点判断有无环。

---

## 2.6 回溯

### 46. 全排列

**必须会：** `path + used`。

### 78. 子集

**必须会：** 每个递归节点都可以收集答案，使用 `start` 控制下一层选择范围。

### 39. 组合总和

**必须会：**
- 组合问题避免顺序重复；
- 当前元素可以重复选择；
- 排序后根据剩余 target 剪枝。

---

## 2.7 二分 / 栈 / 堆

### 35. 搜索插入位置

**必须会：** 标准二分模板以及最终返回 left 的含义。

### 34. 查找第一个和最后一个位置

**必须会：** 把“找 target”转成“找左边界 / 右边界”。

### 33. 搜索旋转排序数组

**必须会：** 每轮至少一半仍然有序，根据 target 是否落在有序半边决定舍弃哪一半。

### 20. 有效的括号

**必须会：** 左括号入栈，右括号必须与栈顶配对。

### 739. 每日温度

**必须会：** 单调递减栈存“还没等到更高温度的位置”。

### 215. 数组中的第 K 个最大元素

**必须会：**
- 大小为 K 的小顶堆；
- 或理解 quickselect 的平均 O(n) 思路。

---

## 2.8 贪心

### 55. 跳跃游戏

**必须会：** 维护当前能到达的最远位置；如果当前下标已经超过最远可达位置，则失败。

### 45. 跳跃游戏 II

**必须会：** 把问题理解成 BFS 层：当前层能覆盖 `[start, end]`，扫描这一层得到下一层最远边界。

---

## 2.9 动态规划

### 70. 爬楼梯

**必须会：** 从状态定义推出 Fibonacci 型转移。

### 198. 打家劫舍

**必须会：**
- 当前位置偷 / 不偷；
- `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。

### 322. 零钱兑换

**必须会：**
- 完全背包；
- `dp[x]` 表示凑出金额 x 的最少硬币数；
- 不可达状态初始化。

### 300. 最长递增子序列

**必须会：**
- O(n²) DP 的状态定义；
- 知道 O(n log n) 的 `tails + 二分` 优化含义。

### 416. 分割等和子集

**必须会：**
- 总和必须为偶数；
- 转成容量为 sum/2 的 0/1 背包；
- 一维优化时容量必须倒序。

### 1143. 最长公共子序列

**必须会：**
- `dp[i][j]` 表示两个前缀的 LCS；
- 相等与不相等两种转移。

# 3. 9 道 M2：理解机制，不能成为盲区

## 11. 盛最多水的容器

**为什么是 M2：** 代码很短，但关键是证明“为什么移动较短的一侧不会漏掉最优解”。

## 42. 接雨水

**为什么是 M2：** 能用前后缀最大值写出来即可；进一步理解双指针为何成立。

## 438. 找到字符串中所有字母异位词

**为什么是 M2：** 是固定滑窗代表题，用来补齐“固定长度窗口”这一支。

## 238. 除了自身以外数组的乘积

**为什么是 M2：** 重点是“前缀信息 + 后缀信息合并”，属于非常通用的数组技巧。

## 240. 搜索二维矩阵 II

**为什么是 M2：** 关键在于从右上角或左下角出发，每一步都能排除一整行或一整列。

## 146. LRU 缓存

**为什么是 M2：** 结构设计题，要求理解 O(1) 查询 + O(1) 删除/插入为什么需要“哈希表 + 双向链表”。

## 124. 二叉树中的最大路径和

**为什么是 M2：** 树形 DP 代表题。重点区分：
- 向父节点返回的只能是一条单边路径；
- 全局答案可以同时连接左右两边。

## 79. 单词搜索

**为什么是 M2：** 网格回溯的完整代表，重点是“访问标记 → 递归 → 恢复”。

## 72. 编辑距离

**为什么是 M2：** 二维 DP 的状态设计价值极高，但不建议机械背转移式；应从“插入 / 删除 / 替换”三种最后操作推导。

# 4. 其余 51 道怎么处理

“非母题”不等于“可以不做”。它们主要承担四种作用：

1. **母题变体**：检查你是否真的掌握 Pattern，而不是只会背母题代码；
2. **边界强化**：例如去重、原地修改、复杂链表连接；
3. **特殊数据结构**：例如 Trie、双堆、随机指针链表；
4. **Hard 强化**：用于二刷之后提高上限。

推荐学习顺序：

```text
先做 M1
  ↓
能独立写出 + 能口述 invariant
  ↓
做同类非母题，验证迁移能力
  ↓
补 M2
  ↓
最后再集中处理剩余 Hard / 特殊技巧
```

# 5. 母题的通过标准

一题只有同时满足下面条件，才应该在 README 中真正标成“掌握”：

- [ ] 不看答案能识别 Pattern；
- [ ] 能说清楚暴力解法为什么慢；
- [ ] 能在 15–20 分钟内独立写出主解法；
- [ ] 能说出核心 invariant / 状态定义；
- [ ] 能给出时间、空间复杂度；
- [ ] 能解释至少一个高频边界条件；
- [ ] 隔 7–14 天后仍能重新写出。

对于 M2，可把“15–20 分钟完全独立写出”放宽为：**能在少量提示后恢复完整解法，并能解释正确性。**
